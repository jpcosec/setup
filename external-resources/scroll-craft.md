# scroll-craft

## Summary

_One paragraph: what this resource is and why it matters to this setup._

Agent skill (plus Claude Code plugin) for building premium scroll-driven websites with a real design standard: design workflow, taste references (hero depth, feel, uniqueness), engine (scrollcraft.css/js), and verification tooling (doctor.mjs, shoot.mjs, serve.mjs). v0.3.0 ships the process behind ten approved sites. MIT.

## How it's used

_How the resource is used in this setup: commands, hooks, workflows._

Not installed. Installable as Claude Code plugin (marketplace.json) or by copying plugins/nateherk-design/skills/scroll-craft into an agent skills dir; the agent composes the engine + references to produce and verify scroll-driven sites.
