# Bolt Slides

## Summary

_One paragraph: what this resource is and why it matters to this setup._

Presentation decks as working web apps: one prompt in, the agent builds an interactive, responsive deck (bespoke layouts, real typography, live data, 3D, working prototypes). MIT. Ships a React/Vite deck framework (src/deck + ~30 slide components) and a .bolt/skills/slides SKILL.md any agent (Claude Code, Codex, Cursor, Bolt) can compose.
