# AgentsRoom

## Summary

_One paragraph: what this resource is and why it matters to this setup._

Proprietary desktop app (macOS/Windows/Linux) to pilot multiple coding agents: one screen with per-agent terminals, live status (thinking/ready/stuck/waiting), desktop notifications, roles, prompts, memory and backlog per project. Supports 14 providers (Claude, Codex, Copilot CLI, Cursor, ...), launching each provider CLI natively; BYOK, multi-account.

## How it's used

_How the resource is used in this setup: commands, hooks, workflows._

Not installed; closed product distributed via /es/download. Overlaps with Herdr's role (many agents, many projects, one surface) but as a closed desktop app instead of a terminal workspace manager.
